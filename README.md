# Coin Bot — Telegram-бот с внутренней валютой и продажей видео

## Что уже умеет

- Регистрация пользователей, баланс коинов
- Каталог видео с ценой в коинах
- Покупка видео за коины (выдача файла или ссылки на приватный канал)
- Реферальная система: ссылка вида `t.me/ваш_бот?start=ref<id>`, бонус рефереру
  при первом пополнении приглашённого
- Пополнение баланса:
  - **вручную** — пользователь переводит на Kaspi/карту, присылает скриншот,
    админ подтверждает кнопкой в чате → коины начисляются автоматически
  - **криптой через CryptoBot** — опционально, если вписать токен в `.env`
- Админ-команды: `/addvideo`, `/addcoins`, `/stats`

## Установка (Windows / VS Code)

1. Установи Python 3.11+ (при установке отметь галочку "Add to PATH").
2. Открой папку `coin_bot` в VS Code.
3. Открой терминал в VS Code (Ctrl+`) и выполни:

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

На macOS/Linux вместо `venv\Scripts\activate` используй `source venv/bin/activate`.

4. Скопируй `.env.example` в `.env` и заполни:
   - `BOT_TOKEN` — получи у [@BotFather](https://t.me/BotFather)
   - `ADMIN_IDS` — твой telegram id (узнать у [@userinfobot](https://t.me/userinfobot))
   - `PRIVATE_CHANNEL_ID` — id приватного канала, если будешь выдавать доступ через него
   - реквизиты Kaspi/карты

5. Запусти бота:

```
python main.py
```

## Как добавить видео

В чате с ботом (от имени админа) напиши `/addvideo` и следуй подсказкам.
Можно прислать само видео файлом (тогда бот хранит `file_id` и отправляет
его напрямую) либо прислать ссылку на пост в приватном канале — тогда бот
просто выдаёт эту ссылку после оплаты.

**Важно:** если используешь приватный канал — добавь бота туда администратором,
и генерируй одноразовые/ограниченные по времени ссылки через
`bot.create_chat_invite_link(chat_id, member_limit=1, expire_date=...)`,
чтобы одну ссылку нельзя было слить всем подряд. Этого пока нет в коде —
добавь при следующей доработке.

## Как подтверждать оплаты вручную

Когда пользователь присылает скриншот, тебе как админу приходит сообщение
с фото и кнопками «Подтвердить» / «Отклонить». При подтверждении коины
начисляются автоматически, и если это первое пополнение приглашённого —
рефереру тоже начисляется бонус.

## Что стоит доработать дальше (я специально оставил как задел)

1. **Одноразовые ссылки на канал** вместо статичной ссылки в БД —
   через `create_chat_invite_link` с `expire_date` и `member_limit=1`.
2. **Защита от накрутки рефералов** — например, начислять бонус только
   после N дней активности приглашённого, либо ограничить по IP/устройству
   (в Telegram это сложно, но можно хотя бы делать бонус меньше и требовать
   подтверждённое пополнение, что уже реализовано).
3. **Категории видео** и постраничная навигация в каталоге, если видео станет много.
4. **Автоматическая проверка крипто-платежей через вебхук**, а не только
   по нажатию «Я оплатил» (см. документацию Crypto Pay API про webhooks).
5. **Логи и бэкапы БД** — `bot.db` — это обычный SQLite-файл, не забывай копировать его.

## Структура проекта

```
coin_bot/
  main.py            — запуск бота
  config.py           — чтение .env
  database.py         — вся работа с SQLite
  keyboards.py        — инлайн-клавиатуры
  states.py           — состояния FSM (диалоги)
  handlers/
    user.py            — меню, баланс, каталог, покупка, реферальная ссылка, ручное пополнение
    admin.py            — подтверждение оплат, добавление видео, статистика
    payment.py           — интеграция с CryptoBot
  requirements.txt
  .env.example
```

## Промпт, чтобы продолжить с ИИ в VS Code

Когда будешь дорабатывать через ИИ-ассистента в VS Code, можно писать так:
"Вот мой проект coin_bot (aiogram 3, SQLite). Хочу добавить [фичу].
Не ломай существующую структуру БД, добавляй миграции аккуратно."
Так ассистент будет видеть контекст и не переписывать всё с нуля.
